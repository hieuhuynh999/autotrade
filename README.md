# local-trader

Bot momentum khung 1 giờ, chạy trên máy bạn. Dữ liệu nến và funding lưu trong SQLite. Một vị thế mỗi lần, khối lượng bằng một phần vốn, cắt lỗ cứng, và dừng mở lệnh mới khi lỗ trong ngày chạm ngưỡng.

Lệnh demo chỉ đi tới `https://demo-fapi.binance.com`. Tool từ chối host của Binance thật.

Cách cài và kiểm thử nằm trong [docs/kiem-thu.md](docs/kiem-thu.md).
